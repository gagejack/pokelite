# Move Sound Effects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every attack in a battle plays a Gen 1 (RBY) sound effect matched to the move being used.

**Architecture:** A pure-data module maps all 72 move names to sound-file stems (no asset imports, so Node can test it). A thin binding module imports the 53 `.m4a` files and joins them to that table. `BattleCard` plays the resolved URL at projectile launch. Source WAVs are converted offline to 64 kbps mono AAC — 18.7 MB becomes under 1 MB.

**Tech Stack:** React 19, Vite 7, `node:test` + `node:assert/strict`, `afconvert` (macOS built-in).

## Global Constraints

- **Test runner is `node --test`, invoked as `npm test`.** Vitest is NOT installed. Tests use `import test from 'node:test'` and `import assert from 'node:assert/strict'`, and live beside their source as `*.test.js` (see `src/game/shop.test.js`).
- **Node cannot import asset files.** Importing a module that statically imports `.png`/`.m4a` fails with `ERR_UNKNOWN_FILE_EXTENSION`. Any module a test imports must contain only plain JS. This is why the mapping is split across two files.
- **Move names are PokéAPI kebab-case**, sourced from `src/game/typeMoves.js` (18 types × 4 tiers = 72 slots).
- **Only primary sound files are used** — no trailing digit, and no `Direct` / `Single` / `Delay` / `(LOOP)` suffix.
- **Never import from the 328-file source pack** at `src/assets/sounds/GEN 1 SFX - Attack Moves - RBY/`. It stays in the repo as reference only. Runtime imports come from `src/assets/sounds/moves/`.
- Spec: `docs/superpowers/specs/2026-08-02-move-sfx-design.md`

## File Structure

| File | Responsibility |
| --- | --- |
| `scripts/encodeMoveSfx.mjs` (create) | One-time offline WAV → `.m4a` conversion of the 53 referenced sounds. |
| `src/assets/sounds/moves/*.m4a` (create) | 53 encoded sounds, committed. |
| `src/game/moveSounds.data.js` (create) | Pure data: move name → file stem. Node-testable. |
| `src/game/moveSounds.data.test.js` (create) | Asserts all 72 moves resolve; guards unknown input. |
| `src/game/moveSounds.js` (create) | Imports the 53 `.m4a` files, exports `getMoveSound(name)` → URL. Vite-only. |

| `src/components/BattleCard.jsx` (modify) | Play the move sound at projectile launch. |

- [ ] **Step 1: Write the encoding script**

Create `scripts/encodeMoveSfx.mjs`:

```js
// One-time offline conversion of the Gen 1 SFX this game references.
//
// The source pack is stereo 44.1kHz 16-bit WAV — wildly oversampled for Game
// Boy audio. The 53 files we reference total 18.7MB, against an app bundle of
// roughly 1MB. At 64kbps mono AAC they come in around 25x smaller.
//
// Run once with: node scripts/encodeMoveSfx.mjs
// Requires macOS (afconvert ships with the OS). Commit the output.

import { execFileSync } from 'node:child_process'
import { mkdirSync, existsSync, statSync, readdirSync } from 'node:fs'
import { join } from 'node:path'

const SRC = 'src/assets/sounds/GEN 1 SFX - Attack Moves - RBY'
const OUT = 'src/assets/sounds/moves'

// The 53 primary sounds referenced by src/game/moveSounds.data.js.
const FILES = [
  'Absorb', 'Acid', 'AuroraBeam', 'Bite', 'Blizzard', 'BodySlam', 'Bubblebeam',
  'Confusion', 'Cut', 'Dig', 'DizzyPunch', 'DoubleKick', 'DragonRage',
  'Earthquake', 'Ember', 'Explosion', 'FireBlast', 'Flamethrower', 'FurySwipes',
  'Gust', 'Headbutt', 'HornDrill', 'HydroPump', 'HyperBeam', 'HyperBeamLaser',
  'IceBeam', 'KarateChop', 'Lick', 'NightShade', 'PoisonPowder', 'Psybeam',
  'Psychic', 'Psywave', 'RazorLeaf', 'RockSlide', 'RockThrow', 'Screech',
  'SkullBash', 'SkyAttack', 'Slash', 'Sludge', 'SolarBeam', 'Swift', 'Tackle',
  'Thunder', 'ThunderPunch', 'ThunderShock', 'Thunderbolt', 'Toxic', 'VineWhip',
  'WaterGun', 'Whirlwind', 'WingAttack',
]

mkdirSync(OUT, { recursive: true })

let inBytes = 0
let outBytes = 0
const missing = []

for (const stem of FILES) {
  const src = join(SRC, `${stem}.wav`)
  const out = join(OUT, `${stem}.m4a`)
  if (!existsSync(src)) { missing.push(stem); continue }
  execFileSync('afconvert', ['-f', 'm4af', '-d', 'aac', '-b', '64000', '--mix', src, out])
  inBytes += statSync(src).size
  outBytes += statSync(out).size
}

if (missing.length) {
  console.error(`MISSING ${missing.length} source file(s): ${missing.join(', ')}`)
  process.exit(1)
}

const mb = n => (n / 1048576).toFixed(2)
console.log(`encoded ${readdirSync(OUT).length} files`)
console.log(`${mb(inBytes)}MB -> ${mb(outBytes)}MB`)
```

### Task 4: Play a sound by URL

**Files:**
- Modify: `src/lib/sound.js`

**Interfaces:**
- Consumes: the existing `isMuted()` in the same file.
- Produces: `playSoundUrl(url: string, opts?: { volume?: number }): void` — fire-and-forget, never throws.

`src/lib/sound.js` already exports `playSound(name, { volume })` for keys in its own `SOUNDS` registry, plus `isMuted()` / `setMuted()`. Move sounds arrive as resolved URLs rather than registry keys, so they need a sibling entry point. Both share one cache.

- [ ] **Step 1: Add the function**

In `src/lib/sound.js`, add below the existing `playSound` function:

```js
/**
 * Play a sound by resolved URL. For callers that already hold a bundled asset
 * URL (move SFX) rather than a key in the SOUNDS registry.
 *
 * Shares the same cache as playSound, keyed by URL, so a sound retriggering
 * before it finished rewinds instead of layering. That is deliberate: one
 * attack should make one audible sound even at 3x battle speed.
 *
 * @param {string} url
 * @param {{ volume?: number }} [opts] volume 0–1, default 0.6
 */
export function playSoundUrl(url, { volume = 0.6 } = {}) {
  if (!url || isMuted()) return

  try {
    let audio = cache.get(url)
    if (!audio) {
      audio = new Audio(url)
      audio.preload = 'auto'
      cache.set(url, audio)
    }
    audio.volume = Math.min(1, Math.max(0, volume))
    audio.currentTime = 0
    audio.play?.().catch(() => {})
  } catch {
    /* Audio unavailable (SSR, locked-down browser) — stay silent. */
  }
}
```

## Notes for the implementer

- **`entry.moveName` can be the literal string `'(no move)'`** — `src/game/battle.js` writes it when an attacker has no move. `getMoveSound` returns `undefined` for it through the normal unknown-name path, so it plays silently. Task 2's test pins this.
- **Three types sound flat across tiers by design** — `dark` uses `Bite` for all four tiers, `ground` uses `Dig` for three of four, `fighting` uses `KarateChop` for three of four. This is inherited from the animation aliases, which make the same compression visually. Accepted for this pass; do not "fix" it.
- **Do not add vitest.** The project runs `node --test`. If a test needs an asset import, the module under test is structured wrong — split the data out, as Tasks 2 and 3 do.
- **Do not import from the source pack** at `src/assets/sounds/GEN 1 SFX - Attack Moves - RBY/`. Its 328 WAVs total 105 MB and must never reach the bundle.
